# Identifying the Acquisition Shifts That Break Few-Shot Industrial Anomaly Detection

Code, per-image scores, preregistrations and analysis scripts for the paper
*Identifying the Acquisition Shifts That Break Few-Shot Industrial Anomaly
Detection: A Controlled Attribution Across Representation Families.*

Few-shot industrial anomaly detection on frozen features is chosen for
deployability, and its failure mode in deployment is benign acquisition change
being scored as a defect. This repository contains everything needed to
reproduce the measurement of **which** change, **to which representation**, at
**what strength** — including the results that did not come out the way we
predicted.

Every number in the paper is produced by these scripts from the result files in
`reports/`. Nothing in the manuscript is transcribed by hand: the 18 tables and
340 inline values are generated by `make_tables.py` and `make_tables_m2ad.py`.

---

## What runs on a bare clone

Two of these need no dataset at all:

```bash
python3 experiment/s1/make_tables_m2ad.py     # 由 reports/ 重新生成 M2AD 的全部表格与 46 个宏
python3 -c "import json; d=json.load(open('reports/r2/tone_index_validation.json')); \
  print(d['tone_range'], d['spatial_range'], d['separated'], round(d['gap'],4))"
```

The second reads the 18 labelled cells behind the tone-dominance index check, so
the separation can be verified arithmetically without MVTec in hand.

These three need the datasets in place (see *Reproducing the results*):

```bash
python3 experiment/s1/verify_m2ad_meta.py          # M2AD 标签语义的五条断言（需 M2AD 元数据）
python3 experiment/s1/m2ad_physical.py --validate  # 重算上面那 18 个单元（需 MVTec）
python3 experiment/s1/verify_m2ad_pipeline.py      # 管线自检（第 1 项需 MVTec，第 2/3 项不需要）
```

`verify_m2ad_pipeline.py` is the one worth reading. It feeds the analysis two
synthetic result sets — one with a known architecture effect, a known
sign-inconsistent pretraining effect and a known monotone relation to the tone
index; one with no effect at all but a shared per-unit random term, which is the
configuration that makes a paired design manufacture false positives. The first
must recover all three planted effects, the second must leave all six tests
non-significant. Both are asserted, not eyeballed.

## Preregistrations

Two studies here were preregistered before the data were seen.

| File | Study | Outcome |
|---|---|---|
| `experiment/s1/PREREGISTRATION.md` | Defect physical signature × illumination mode interaction (MVTec AD) | **All three predictions failed.** Reported as a negative result. |
| `experiment/s1/M2AD_PREREGISTRATION.md` | Representation ordering under real view–illumination shift (M2AD) | Three of four predictions held; **M4 (rank inversion) was falsified.** |

The M2AD document carries three amendments, each with a SHA-256 and a
timestamp. None touches a hypothesis or a decision rule. Two predate the first
run; the third predates any M2AD AUROC being read. Amendments B and C each
replace the tone-dominance index after it failed a ground-truth check — the
first on the synthetic grid, the second on M2AD's own images. Both failures are
written up rather than quietly fixed, because the checks that caught them are
the transferable part.

## Reproducing the results

### 1. Datasets

Not redistributed here. MVTec AD and AeBAD-S require accepting their licences;
M2AD is Apache-2.0 and has a download script.

```bash
bash experiment/s1/fetch_m2ad.sh     # M2AD, 153 GB, resumable, 单实例锁
```

Expected layout under the repository root (override with `IADSHIFT_ROOT`):

```
data/mvtec_anomaly_detection/     MVTec AD
data/AeBAD_S_domains/             AeBAD-S, 由 build_aebad_domains.py 生成
data/M2AD/images/  data/M2AD/meta_unsupervised.json
experiment/AnomalyDINO/           上游参考实现（见下）
```

### 2. Upstream reference implementation

The detector is [AnomalyDINO](https://github.com/dammsi/AnomalyDINO) at commit
`b9d1c26`, used unmodified. `verify_upstream_defects.py` reproduces the five
defects reported in the paper against that unmodified checkout; four are in the
custom-dataset path and the fifth — a morphology operation applied to an
`(N_patches, 1)` column vector — changes conclusions, which is why all masked
results were discarded and the grid re-run.

### 3. Sweeps

```bash
# MVTec 受控光照扰动网格
python3 experiment/s1/mvtec_illum.py --backbone dinov2_vits14 --agg meantop1p \
        --out reports/mvtec_illum.json --dump-scores reports/scores.npz

# AeBAD-S 真实偏移
python3 experiment/s1/replay_protocol.py --backbone dinov2_vits14 \
        --out reports/aebad.json

# M2AD 真实视角×光照（预注册协议：4 视角, k=4, 4 seeds）
python3 experiment/s1/m2ad_shift.py --backbone dinov2_vits14 --categories Bird \
        --views 000 090 180 270 --k 4 --seeds 4 --out reports/m2ad/out.json
```

A sharded work queue is provided for multi-GPU runs: `m2ad_enqueue.sh` extracts
each category as its download completes and enqueues one task per backbone;
`m2ad_worker.sh <gpu_id>` claims tasks atomically via `mv`.

### 4. Analysis

```bash
python3 experiment/s1/analyze_r2.py          # MVTec 主分析
python3 experiment/s1/analyze_r2_scores.py   # 部署口径与两类不确定度区间
python3 experiment/s1/analyze_m2ad.py        # M2AD 预注册检验 M1–M4
python3 experiment/s1/analyze_m2ad.py max    # 同上，PatchCore 聚合口径
```

## A result that does not replicate under both aggregations

The preregistration fixes `mean_top1p` (AnomalyDINO) as primary and commits to
running `max` (PatchCore-style) as a robustness check. They do not agree on how
strong the evidence is, and the paper reports the preregistered one rather than
the more favourable one:

| Test | `mean_top1p` | `max` |
|---|---|---|
| M1 architecture, self-sup. arm | +0.021 [+0.012, +0.030] ✓ | +0.021 [+0.011, +0.032] ✓ |
| M1 architecture, supervised arm | +0.012 [+0.002, +0.022] ✓ | +0.013 [+0.003, +0.024] |
| M3 tone-dominance ρ | +0.833 [+0.367, +1.000] ✓ | +0.617 [−0.083, +1.000] |

(✓ = survives Holm–Bonferroni over the preregistered family of six.)

Every point estimate keeps its sign and roughly its size. What changes is
precision: `max` scores an image by a single patch distance while `mean_top1p`
averages the top one percent, so it is the higher-variance statistic on the same
features and the same bank. A reader who prefers the PatchCore aggregation
should read M3 as directionally supported but not established.

## Hardware and cost

All results were produced on 4 × Tesla V100-DGXS-32GB. The binding cost is the
1-NN search, not the backbone: at 448 px a ResNet `layer2+layer3` read gives
3136 patches per image against 1024 for DINOv2 ViT-S/14, and the full 12-view
M2AD design was measured at roughly 37 GPU-hours before being reduced to four
viewpoints (preregistration amendment A). `bench_cost.py` reproduces the
per-representation latency and peak-memory table.

## Layout

```
experiment/s1/
  fscache.py            特征缓存 + bank 组装引擎（1-NN 下 bank 距离 = 成员逐元素最小值）
  backbones_ext.py      2×2 识别设计的 backbone 分派 + 层深对照
  illum.py              六种参数化光照扰动，severity 0 逐位恒等于原图
  mvtec_illum.py        MVTec 扰动网格
  replay_protocol.py    AeBAD-S 真实偏移
  m2ad_shift.py         M2AD 真实视角×光照
  m2ad_physical.py      物理描述量与色调主导指数（--validate 自带有效性检验）
  analyze_*.py          统计分析
  verify_*.py           自检脚本
  make_tables*.py       论文表格与行内宏的唯一来源
reports/                全部结果文件与逐图分数
```

Scripts derive the project root from their own location, so the repository works
wherever it is cloned. Set `IADSHIFT_ROOT` to override.
